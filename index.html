Program A-1 Library Management System

Library record management using structures and dynamic memory

Develop a program in C to define a structure Book with fields such as Book_ID, Title, Author, Price, and Status; dynamically allocate memory for N books; and implement create(), display(), search(), issueBook(), and returnBook() through a menu-driven system. 

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct Book {
    int Book_ID;
    char Title[30];
    char Author[30];
    float Price;
    char Status[15];
};

struct Book *list;
int n;

void create() {
    int i;
    printf("Enter number of books: ");
    scanf("%d", &n);
    list = (struct Book *)malloc(n * sizeof(struct Book));
    for (i = 0; i < n; i++) {
        printf("\nEnter details of book %d\n", i + 1);
        printf("Book ID   : ");
        scanf("%d", &list[i].Book_ID);
        printf("Title     : ");
        scanf(" %[^\n]", list[i].Title);
        printf("Author    : ");
        scanf(" %[^\n]", list[i].Author);
        printf("Price     : ");
        scanf("%f", &list[i].Price);
        strcpy(list[i].Status, "Available");
    }
}

void display() {
    int i;
    printf("\n%-8s%-25s%-20s%-10s%-10s\n", "ID", "Title", "Author", "Price", "Status");
    for (i = 0; i < n; i++)
        printf("%-8d%-25s%-20s%-10.2f%-10s\n",
               list[i].Book_ID, list[i].Title,
               list[i].Author, list[i].Price, list[i].Status);
}

int search(int id) {
    int i;
    for (i = 0; i < n; i++)
        if (list[i].Book_ID == id)
            return i;
    return -1;
}

void issueBook() {
    int id, pos;
    printf("Enter Book ID to issue: ");
    scanf("%d", &id);
    pos = search(id);
    if (pos == -1)
        printf("Book not found.\n");
    else if (strcmp(list[pos].Status, "Issued") == 0)
        printf("Book is already issued.\n");
    else {
        strcpy(list[pos].Status, "Issued");
        printf("Book \"%s\" issued successfully.\n", list[pos].Title);
    }
}

void returnBook() {
    int id, pos;
    printf("Enter Book ID to return: ");
    scanf("%d", &id);
    pos = search(id);
    if (pos == -1)
        printf("Book not found.\n");
    else if (strcmp(list[pos].Status, "Available") == 0)
        printf("Book was not issued.\n");
    else {
        strcpy(list[pos].Status, "Available");
        printf("Book \"%s\" returned successfully.\n", list[pos].Title);
    }
}
Program A-2 Stack Operations

Menu-driven implementation of stack with palindrome check

Use an integer stack with array implementation. The program should support push, pop, palindrome checking, overflow/underflow detection, and display of current stack content.

  • Operations: push, pop, display, palindrome, overflow, underflow
  • Principle: LIFO (Last In First Out)
  • Applications: expression evaluation, backtracking, recursion simulation
Program A-3 Queue Simulation

Printer queue using queue data structure

Simulate a printer job queue with operations to add a print job, process a job, display pending jobs, count waiting jobs, and demonstrate overflow and underflow.

  • Queue uses FIFO logic
  • Maintains front and rear positions
  • Useful for process scheduling and buffering
Program A-4 Linked List

Singly linked list of student records

Create a linked list using front insertion, display the records and count the nodes, insert/delete at the beginning or end, and search by USN.

Program A-5 Binary Tree

Binary tree creation with level-order insertion and traversal

Create a binary tree by inserting integer elements entered by the user in level order, and implement createTree(), preorder(), inorder(), and postorder() traversals.

Program A-6 Graph

Graph representation using adjacency matrix and DFS/BFS

Build a graph of cities in adjacency matrix form and print all nodes reachable from a starting city using DFS or BFS traversal.
